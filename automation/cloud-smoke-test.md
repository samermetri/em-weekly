2. Retrieve one approved PubMed record and one official society guidance page or use official-domain web search. Record exact URLs and dates. Stop for an inaccessible tool; do not use a desktop proxy.

Write only state/audits/cloud-connection-test.json with connectionTestSchema: testedAt, environment (actual hosted environment name), repository, readCommit, sourceUrls, writeCommit (initially null), workflowRunUrl (initially null), deploymentUrl (initially null), status:'in-progress'. Read the run URL and matching commit, wait for success, then open the public Pages URL signed out, a source-linked article, the issue, and browser print view. Read back the successful deployment state.
5. Record exact write commit, workflow run, deployment URL and status:'passed' in the test audit; set state/publishing.json cloudConnection to tested status with the same evidence. Do not self-certify any unperformed step.
6. Only now enable the two recurring tasks in a supported cloud scheduler. Use America/Los_Angeles: daily 07:00 and Monday 08:00. Keep the timezone in the scheduler. Copy automation/daily.md and automation/weekly.md unchanged, and record schedule IDs, environment name and a first-run result in automation/schedules.json. Enabling configuration requires a reviewed setup change; normal editorial prompts cannot change it.

Use existing supported GitHub App access restricted to this repository when available. For a supported cloud secret store with a fine-grained token, use only samermetri/em-weekly, Contents read/write, Actions read/write, Metadata read; add no account-wide scope. Do not put the desktop Keychain credential, personal credential files or tokens into the repository, task prompts, logs, site or chat. A read-only GitHub app is insufficient. A configured repository sandbox may provide its own supported Git authentication; test push and dispatch independently.

If any stage fails: recurring schedules stay disabled. Preserve the working site and saved prompts, record the exact missing capability, and tell the owner which connection/permission or cloud environment needs configuration. Do not create a local heartbeat as a substitute.
